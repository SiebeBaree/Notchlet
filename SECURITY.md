# Security policy

Notchlet reads credentials for Claude Code and Codex from your machine to query their usage endpoints. Anything that could leak those credentials, send them anywhere unexpected or widen what the app reads is a security issue.

## Reporting

Please do not open a public issue for vulnerabilities. Use
[GitHub private vulnerability reporting](https://github.com/SiebeBaree/Notchlet/security/advisories/new)
instead. You should get a response within a week.
